# Product Roadmap — VIBE (AI for Humanity)

---

## 1. Implemented & Verified in Code

- [x] **Full 12-Section Responsive Landing Page**: Header, Hero, Problem Section, How VIBE Works, Features Highlight, Competitive Matrix, Trust & Safety, Business Model Preview, Evidence-Led Research & Citations, FAQs, Final CTA, and Emergency Footer.
- [x] **Mandatory Caution Statements**: Displayed prominently on landing, safety, and evidence pages.
- [x] **Public Informational Routes**: `/about`, `/how-it-works`, `/safety`, `/business`, `/privacy`, `/terms`.
- [x] **User Authentication & Session Management**: Registration, Login, Logout, Session Cookie verification, demo accounts for instant evaluation.
- [x] **Passenger Profile & Interest Management**: Profile alias, bio, interests multi-select, skills to share, skills to learn, languages, and discovery opt-in.
- [x] **Train Journey Setup**: Train number, travel date validation (rejecting past dates), boarding and destination station configuration.
- [x] **Explainable AI Matching Engine**: Weighted compatibility scoring (0 to 100), transparent plain-English justifications, and privacy exclusions.
- [x] **Train-Specific Communities & Groups**: Group creation, category tags, community rules, join/leave controls, member count updates, and live group chat.
- [x] **1-to-1 Conversations & Messaging**: Conversation lists, message sending, length checks, timestamps, and auto-scroll.
- [x] **Two-Way Blocking System**: Mutual communication severance, discovery hiding, and non-alarming confirmation.
- [x] **Multi-Category Safety Reporting**: Harassment, spam, abusive conduct reporting with automatic block coupling.
- [x] **Restricted Moderator Interface (`/admin`)**: Role-based access control, report triage, status updates, moderator notes, and resolution actions.
- [x] **Train Engagement & Activities**:
  - Indian Railways Heritage Trivia Quiz (scoring, explanation, points calculation)
  - Hindi - English Travel Language Exchange (interactive flashcards)
  - Small Talk Saves Lives Travel Prompts & Icebreakers
- [x] **Achievements & Gamification**: Points tally, progress tracking, and milestone badges.
- [x] **Official Assistance & Help Directory**: RailMadad (139), National Emergency (112), Women Safety (1091), onboard TTE/RPF protocols.
- [x] **Settings & Privacy Controls**: Discoverability toggle, notification preference, and permanent Right to Erasure account deletion.
- [x] **Comprehensive Automated Test Suite**: 21 passing unit, integration, and security tests.

---

## 2. Planned for Post-Hackathon Phase

- [ ] **Offline PWA Sync**: Service Worker caching for offline access during low-connectivity rail tunnels.
- [ ] **Multi-Leg Journey Chains**: Support for passengers with connecting trains at major junction hubs.
- [ ] **Verified Station Guides**: Curated regional culinary stops and station heritage audio guides developed with tourism partners.
- [ ] **WebRTC Voice Rooms**: Ephemeral low-bandwidth audio study rooms for community groups.
- [ ] **Local Multilingual UI**: Full localization in Hindi, Marathi, Tamil, Bengali, Telugu, and Gujarati.

---

## 3. Blocked / Requiring External Railway Credentials

- [ ] **Live PNR & Timetable Integration**: Direct real-time railway API feed (requires formal commercial licensing and partnership with CRIS / IRCTC). Handled via user-provided travel details with explicit non-official labeling.
